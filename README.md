# KI-Nutzungsrahmen

In diesem Modul wird KI (z. B. ChatGPT, Claude, Copilot) gezielt als **Lernpartner** eingesetzt – über das ganze Modul verteilt, mit klaren Leitplanken. Eingeführt wird der Rahmen im letzten Block von [Tag 1](tag-01.md) («KI-Werkstatt 1»), danach folgen an mehreren Tagen kurze **KI-Werkstatt**-Blöcke ([Tag 3](tag-03.md), [Tag 4](tag-04.md), [Tag 6](tag-06.md)) sowie ein informeller Rückblick am [Tag 10](tag-10.md).

## Erlaubt
- Erklärungen einfordern, Konzepte in eigenen Worten zusammenfassen lassen
- Rückfragen stellen, Verständnis vertiefen (KI als sokratischer Tutor/Coach)
- Prompt-Übungen, Testdaten und Übungsbeispiele generieren lassen
- Recherche-Einstieg – **mit anschliessender Prüfung gegen eine offizielle Quelle**

## Nicht erlaubt
- Lernjournal-Reflexionen von der KI schreiben lassen
- KI-Nutzung bei LB1/LB2: Beide Prüfungen finden **ohne elektronische Hilfsmittel** statt
- Eigenleistungspflichtige Kernaufgaben durch KI ersetzen lassen (z. B. Chiffren von Hand knacken, GPG-Setup, LB3-Reflexionen)

## Rolle der KI
KI tritt als **sokratischer Tutor** auf: Sie gibt Hinweise, Rückfragen und Erklärungen – keine fertigen Lösungen. Die kritische Prüfung von KI-Antworten (Faktencheck, Erkennen von Halluzinationen) ist selbst Teil der Lernziele, insbesondere in der KI-Werkstatt an Tag 3.

## Bewertung
Die KI-Nutzung ist **nicht Teil des Bewertungsrasters** (weder bei LB1/LB2 noch bei LB3). Eine informelle Dokumentation eigener Erfahrungen im Lernjournal ist empfohlen, aber freiwillig und nicht notenrelevant.
